
# World War 1914

Ein historisches globales Strategiespiel im Browser.

## Features

- Globale interaktive Weltkarte
- Echtzeit-Spielsystem
- Wirtschaft und Produktion
- Fabrikverbesserungen
- Schiffbau
- Flugzeugverwaltung
- Ressourcenmanagement

## Installation

1. Repository herunterladen.
2. index.html im Browser öffnen.
3. Internetverbindung für die Kartendaten sicherstellen.

## Technologien

- HTML5
- CSS3
- JavaScript
- Leaflet
- GeoJSON / TopoJSON

## Veröffentlichung

Das Projekt kann über GitHub Pages veröffentlicht werden.

## Hinweis

Die erste Karte dient als geografisches Grundgerüst.
Historische Grenzen von 1914 werden später ergänzt.
